# 정기시험 학생 유의사항 교육 웹앱

중학교 정기시험 전에 학생 유의사항과 부정행위 유형을 익히는 교육용 웹앱입니다.
학생은 태블릿으로 각자, 교사는 교실 TV로 함께 쓸 수 있습니다.

- **영상으로 배우기** — 3D 교실에서 또박이·준이·솔이가 상황극으로 설명 (약 3분)
- **게임 1단계 · 책상 점검** — 물건을 끌어서 책상 위 / 가방·사물함 / 제출함으로 정리
- **게임 2단계 · 부정행위를 잡아라** — 학생 14명 교실에서 부정행위 하는 학생 찾기 (시작종 전 → 1~3교시 → 종료령)
- **확인 퀴즈** — 10문제, 풀 때마다 문제가 바뀜
- **한눈에 보기** — 유의사항 전체

오른쪽 위 토글로 `태블릿 · 혼자` / `교실 TV · 함께` 모드를 바꿉니다. 주소 끝에 `?tv`를 붙여도 TV 모드로 열립니다.

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 메뉴·퀴즈·한눈에 보기 |
| `assets/video3d.js` | 3D 영상 (three.js) |
| `assets/video.mp3`, `assets/cues.js` | 영상 음성 트랙과 자막·입 모양 타이밍 (자동 생성) |
| `assets/game.js` | 게임 두 단계 |
| `assets/kit.js`, `assets/scene.css` | 교실·캐릭터 SVG 키트와 장면 스타일 |
| `_build/make_video_audio.py` | 대본에서 음성 트랙을 다시 만드는 스크립트 (`pip install edge-tts numpy`, ffmpeg 필요) |

서버 없이 정적 파일만으로 동작합니다. 대사를 고치려면 `_build/make_video_audio.py`의 `SCRIPT`를 수정하고 실행한 뒤, `assets/video3d.js`의 해당 장면 `beats` 개수를 맞춥니다.

three.js는 MIT 라이선스(`assets/vendor/three.min.js`, r149)입니다.
